# Агент

## Необходимые требования
- ОС Windows
- **rustc 1.96.0**
- **cargo 1.96.0**
- Ключ API для одной из указанных платформ

## Как запускать
- `git clone git@github.com:griagaf/agent.git`
- `cp .env.example .env`
- `Указать ключ в .env`
- `cargo run` — консольный режим
- `cargo run -p agent-app` — окно приложения
